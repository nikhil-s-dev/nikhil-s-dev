# Nikhil S

I'm a software engineer focused on Java, AI/ML, and GPU computing. My projects and interests include large language models (LLMs), retrieval-augmented generation (RAG), model evaluation, and efficient fine-tuning with LoRA and QLoRA. I enjoy building Java tools for LLM testing and performance measurement, and exploring GPU model serving and Kubernetes for AI applications.

## Open-source projects

- [**rag-regress**](https://github.com/nikhil-s-dev/rag-regress): Java regression tests for retrieval quality in RAG systems, with ranking metrics and baseline comparisons.
- [**llm-loadgate**](https://github.com/nikhil-s-dev/llm-loadgate): Java load testing and streaming latency measurements for LLM endpoints.
- [**Financial capability predictor**](https://github.com/nikhil-s-dev/Financial-Capability-Predictor-of-a-Bank-Consumer-using-Exploratory-Data-Analysis): Exploratory data analysis project; the repository contains a report and presentation.

## Experiment plans and research interests

The LoRA pilot includes measured results; the remaining items are planned investigations.

- **[LoRA vs QLoRA T4 pilot](https://github.com/nikhil-s-dev/nikhil-s-dev.github.io/tree/main/experiments/lora-qlora):** measured training time, peak PyTorch GPU memory, and held-out language-model loss for a small single-seed experiment.
- **Production RAG and retrieval evaluation:** document ingestion, hybrid retrieval, reranking, citations, and evaluation using `rag-regress`.
- **GPU inference on Kubernetes:** investigate vLLM/Triton serving, tail latency, reliability, GPU utilization, and cost per token with `llm-loadgate`.
- **Industrial AI and process safety:** explore AI-assisted maintenance and human-reviewed decision support.
- **Healthcare and genomics research:** explore cancer subtype prediction, survival modeling, and a literature-grounded research assistant.
- **Real-time ML feature platform:** explore event-driven feature processing, freshness, and training-serving consistency.
